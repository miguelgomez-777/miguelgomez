# COMP1238 Midterm Notes

## Week 1 - Writing Systems
- One writing system can be used by many languages (the Latin alphabet is used by English, Spanish and French)
- Writing systems differ in what a symbol stands for: a sound, a syllable, or a whole word

## Week 2 - Bits and Bytes
- A bit is 0 or 1, and a byte is 8 bits (256 possible values, 0 to 255)
- Hexadecimal uses 0-9 and A-F: `0xFF` = 255, and `0b1101` = 13
- Hex colours are `#RRGGBB`, so `#FF0000` is pure red

## Week 3 - Structure and Markup
- Markdown link: `[text](url)`. Markdown image: `![alt text](image-url)`
- Escape a special character with a backslash, for example `\#` shows a literal #
- Valid JSON has no trailing comma and uses double quotes for keys

## Week 4 - Typing and Searching
- The `^` symbol is called the caret
- In VS Code search, "Match Whole Word" finds only complete words
- In regular expressions, `\d` matches one digit

## Week 5 - Command Line
- `pwd` prints the current folder, and `cd` changes to another folder
- The pipe `|` sends the output of one command into the next command
